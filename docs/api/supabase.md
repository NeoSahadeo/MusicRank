# Overview

This is the API for Supabase interactions, such as read/write/delete/put/update/patch

The user must be authenticated before querying the endpoints otherwise the
will return and empty array or will silently fail.


## Fetch Rankings

### Get

Returns the rankings from the rankings table

`api/supabase/rankings`

#### Schema

```
create table public.rankings (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  user_id uuid not null default auth.uid (),
  rating smallint null,
  review text null,
  song_id character varying null,
  constraint rankings_pkey primary key (id, user_id),
  constraint rankings_user_id_fkey foreign KEY (user_id) references auth.users (id) on update CASCADE on delete CASCADE
) TABLESPACE pg_default;
```
