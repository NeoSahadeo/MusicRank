# MusicRank

The Music Ranking Platform where you are able to rank and track your music.

# Getting Started (Contributors)

Clone the repository, setup `.env` and run the server (dev).

```bash
git clone --depth=1 git@github.com:NeoSahadeo/MusicRank.git
cd MusicRank
```

Next, you will need to create a [supabase account and setup your db](https://supabase.com/).
Then setup your [Google Auth Login](https://console.cloud.google.com/auth/); GL :)

**.env**

```bash
SUPABASE_AUTH_EXTERNAL_GOOGLE_CLIENT_SECRET="SECWETS!"
SUPABASE_URL=SUPER_SECWET_UWL(NOT REALLY<3 it's public)
SUPABASE_ANON_KEY=ANON_KEY(aka, public key;also public)
```

If everything worked-out, you are now ready to run the server.

```bash
pnpm i
pnpm run dev
```
